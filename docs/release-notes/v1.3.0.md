# PDFCS 1.3.0

**Every page upright, every page the same size.**

This release comes from a real scan: a 93-page photographed copy of IPC J-STD-001J. In 1.2.0, pages 45–93 of that scan came out sideways with no usable text, page edges and margins varied from page to page, and headers and page numbers sat on the very edge or were clipped. All of that is fixed here.

### Highlights
- **Sideways and upside-down pages are turned upright.** Hold the phone however you like. PDFCS sees when the text runs up or down the page and turns it, then reads it both ways up to make sure it is not upside down. Pages that came out as sideways, unsearchable pictures now come out upright as searchable text.
- **Looks like a real document.** Every page goes on one standard paper size (Letter, A4 and other common sizes, picked from the page's shape) with the same margins on every page, like the ST USBLC6-2 datasheet. A tight crop or a crop with extra desk no longer changes the page.
- **Cleaner kept words.** A word PDFCS cannot verify still keeps its original pixels, so it is never misprinted, but those pixels are now black ink on white paper instead of grey camera pixels in a grey box.
- Typeset words no longer run into kept words on the same line.

### Measured
Simulated phone photos, converted end to end on an emulator:
- **Sideways and upside-down photos** of the ST USBLC6-2 datasheet (turned clockwise, anticlockwise and upside down): all upright, **80%** of words word-exact over three pages and 95% on page 1. 1.2.0 read none of these pages.
- **Upright photos** of the same datasheet: 81% over three pages and 95% on page 1, the same as 1.2.0 (82%, 96%). No upright page was turned by mistake.
- **Pages 50, 53 and 76 of the IPC scan**, photographed sideways: all upright on Letter paper, with searchable text and tables.

### Install
Download the APK for your phone below and open it:
- `PDFCS-v1.3.0-arm64-v8a.apk`: almost every phone from the last several years. If unsure, take this one.
- `PDFCS-v1.3.0-armeabi-v7a.apk`: older 32-bit phones.
- `PDFCS-v1.3.0-universal.apk`: works everywhere, but is larger.

It updates PDFCS 1.2.0 in place, and your library is kept. To fix an existing scan such as the IPC one, convert the original photos again for the best result. If you no longer have them, *Make searchable* on the old PDF reads its pages again, but it works from the lower-quality pixels the old PDF kept.

### Requirements
Android 8.0 or newer. The English OCR model is built in. Other languages can be downloaded in Settings.

### Known limitations
- Small print, subscripts and graph labels are often kept as original pixels rather than text. They stay searchable.
- A page photographed with part of it outside the picture can't be completed. Keep the whole page in the frame.
