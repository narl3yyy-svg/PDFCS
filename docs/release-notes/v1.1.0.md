# PDFCS 1.1.0

**Photograph a book. Get a real digital PDF.**

PDFCS now rebuilds every scanned page as a born-digital page:
- Real, selectable text in matching fonts, with bold, italic and colours kept.
- Figures, photos and tables cut out cleanly.
- Pure white paper, and the same page size throughout.

The result reads, searches and highlights like a PDF made on a computer.

### Highlights
- **Verified text.** Every word is checked against the ink on the page before it is printed. Words that can't be verified keep their original pixels, so a misreading never appears as wrong text, and they stay searchable.
- **Better page detection and clean-up.** The page edges are found as straight lines, and shadows and colour casts are removed per colour channel.
- **A full PDF editor:**
  - **Comment:** highlight, underline, strike out, sticky notes, drawing.
  - **Organise:** rotate, delete, move, duplicate, insert, extract, split, combine.
  - **Edit:** watermarks, page numbers, added text, forms, properties.
  - Undo and redo for everything.
- **Protect** with AES-256 passwords and permissions.
- **Convert** to text, Word (.docx) or images, and reduce file size.
- **Analyse** documents: fonts, text coverage, security and suggestions.

### Install
Download `PDFCS-v1.1.0.apk` below and open it on your phone. You may need to allow installing apps
from your browser or file manager. This release is a new app (`com.narl3yyy.pdfcs`) with a new
signing key, so it installs alongside, not over, the previous build.

### Requirements
Android 8.0 or newer. The English OCR model is built in. Other languages can be downloaded in Settings.

### Known limitations
- Digital-text pages support Latin, Greek and Cyrillic scripts. For other scripts, use the *Original photos* output.
- Subscripts, very small print and symbols are often kept as original pixels rather than text.
- If one edge of the page is in deep shadow, the automatic crop can fall short of it. Check the corners in the page editor.
